HOW TO UPLOAD & EDIT CONTENT
============================

1. Log in to the Admin Dashboard
   - Go to: http://localhost:3001/admin (or your website URL /admin)
   - Password: EmmanuelMusic2024!
     (This password can be changed in server.js)

2. FEATURES:

   TAB 1: New Score/Product
   ------------------------
   - Use this to add new sheet music or songs to the "Scores" page.
   - Requires a Title, Price, and Cover Image.
   - Can optionally include PDF, MP3, and YouTube links.

   TAB 2: Edit Text Content
   ------------------------
   - Use this to edit text on the 'Biography' page or 'Home' page.
   - Select the page section from the dropdown (e.g., "Biography Page").
   - The current text will load in the editor.
   - You can edit the text and HTML. Click "Save Text Changes" to apply.
   - BE CAREFUL: Do not delete structural HTML tags like <div> if you don't know what they do. Sticking to <p>, <h1>, <h2> is safe.

   TAB 3: Update Gallery
   ---------------------
   - Use this to upload new photos to the "Gallery" page.
   - You can select multiple photos at once.
   - They appear on the website immediately after upload.

TROUBLESHOOTING
- If changes don't appear, try refreshing the page (Ctrl+R or Cmd+R).
- If the "Loading..." text gets stuck, check your internet connection or restart the server.
